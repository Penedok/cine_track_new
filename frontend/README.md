# Cine Track

Aplicação web para organizar uma biblioteca pessoal de filmes: pesquisar, filtrar por gênero, adicionar títulos e acompanhar o que já foi assistido.

Stack: **React 19**, **TypeScript**, **Vite 8**.

---


## Requisitos rápidos (checklist)

1. Instalar Node.js 20.19+ (ou 22.12+).
2. Entrar na pasta do projeto.
3. Rodar `npm install`.
4. Desenvolvimento: `npm run dev` → abrir `http://localhost:5173`.
5. Produção: `npm run build` e, se quiser testar, `npm run preview`.
